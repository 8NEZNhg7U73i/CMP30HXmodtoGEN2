BIOS GUIDE

Nạp Key BIOS & Giữ Tensor Core (Valorant Win 11)

⚠️ Dùng điện thoại chụp lại hướng dẫn này trước khi khởi động lại máy!
Vị trí file chứng chỉ (CMP40HX_Key.cer):
1. C:\CMP40HX_Key.cer
2. Desktop\CMP40HX_Key.cer
BƯỚC 1
Vào BIOS Setup: Tìm tab Security/Boot → Key Management (chọn Custom Mode).
BƯỚC 2
Nạp cert vào db: Chọn Authorized Signatures (db) hoặc Append db → nạp file CMP40HX_Key.cer (giữ nguyên key Microsoft).
BƯỚC 3
Bật Secure Boot: Đặt Secure Boot thành ENABLED.
BƯỚC 4
Lưu cấu hình: Nhấn F10 → Yes để khởi động lại.
